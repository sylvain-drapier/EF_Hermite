affichage_interactif module¶

Vues interactives (Plotly + ipywidgets) pour Hermitte_NL_Classes¶

Complète pbEF_poutre.Affichage (matplotlib, figures statiques) sans le modifier : le module ne fait que LIRE l’objet problème (noeuds, éléments, ddls, modes).

Utilisation dans un notebook

import affichage_interactif as AI
AI.vue(pb)                      # statique : choix du champ, survol des valeurs
AI.vue_modes(pb)                # flambage / vibration : choix du mode + animation
AI.compare([pb2, pb4, pb8], ['2 élts', '4 élts', '8 élts'], mode=1)
AI.tableau_noeuds(pb).show()    # ddls et réactions aux noeuds
AI.tableau_elements(pb).show()  # géométrie, charges et efforts internes des éléments
AI.tableau_valeurs_propres([pb0, pb1], ['initial', 'modifié']).show()

Sans ipywidgets, les fonctions figure, figure_mode et compare renvoient des figures Plotly utilisables seules (fig.show(), fig.write_html(...)).

Interpolation d’Hermite¶

La déformée est tracée avec les fonctions de forme de l’élément, et non par des segments droits entre noeuds. Dans le repère local (t, n) de l’élément, pour xi = x/le dans [0, 1] :

u(xi) = (1 - xi) u_1 + xi u_2 (linéaire) v(xi) = H1 v_1 + le H2 theta_1 + H3 v_2 + le H4 theta_2 (cubique)

H1 = 1 - 3 xi^2 + 2 xi^3 H2 = xi - 2 xi^2 + xi^3 H3 = 3 xi^2 - 2 xi^3 H4 = -xi^2 + xi^3

Les champs le long de l’élément s’en déduisent (convention du code) :

N = ES du/dx (constant), M = EI d2v/dx2 (linéaire), T = -dM/dx (constant), K = d2v/dx2.

affichage_interactif.Cl_index(pb, num)¶

Position du noeud de numéro num dans pb.nodes_global.

affichage_interactif.amplification_auto(pb, q=None, fraction=0.1)¶

Facteur tel que le plus grand déplacement nodal vaille fraction de la taille de la structure.

affichage_interactif.compare(liste_pb, noms=None, mode=None, hermite=True, ampli=None, n_pts=15, titre=None)¶

Superpose les déformées (mode=None) ou le mode mode de plusieurs problèmes, par exemple plusieurs maillages pour illustrer la convergence en h.

affichage_interactif.ddls_noeuds(pb, q=None)¶

Tableau (nb_noeuds, 3) des ddls (u1, u2, theta) dans le repère de structure. q = None : solution statique pb.dofs ; sinon un vecteur de ddls (mode propre…).

affichage_interactif.figure(pb, champ='u', q=None, ampli=None, hermite=True, representation='couleur', maillage=True, numeros=False, efforts=True, appuis=True, n_pts=15, titre=None)¶

Figure Plotly d’un champ sur la structure.

  • champ : “u”, “N”, “T”, “M”, “K”, “e”, “ES”, “EI” (cf. CHAMPS)

  • representation : “couleur” (champ en couleur sur la déformée) ou “diagramme” (diagramme du champ tracé perpendiculairement aux poutres, côté normale locale n pour les valeurs positives — n = t tourné de +90°, t orienté du noeud 1 vers le noeud 2)

  • ampli : amplification de la déformée (None = automatique)

  • hermite : déformée interpolée par les fonctions d’Hermite (sinon segments droits)

affichage_interactif.figure_mode(pb, k=1, hermite=True, maillage=True, numeros=False, appuis=True, n_images=24, ampli=0.15, n_pts=15)¶

Mode propre k (1 = premier) de pb.mode_min, animé (bouton ▶).

Le mode est normé (plus grande translation = 1) puis amplifié à ampli × taille de la structure.

affichage_interactif.interpole_elem(e, q, n_pts=15, hermite=True)¶

Interpolation sur un élément.

Retournedict avec

  • xi : abscisses réduites (n_pts)

  • X : positions initiales (n_pts, 2)

  • d : déplacements dans le repère de structure (n_pts, 2)

  • n : normale locale (2,) = (-S, C)

  • champs : dict des champs le long de l’élément (toujours calculés avec Hermite)

affichage_interactif.normalise_mode(q)¶

Mode normé : plus grande translation = 1, et positive (le signe d’un mode est arbitraire).

affichage_interactif.tableau_elements(pb, titre='Éléments : géométrie, charges réparties (repère local) et efforts internes')¶

Tableau des éléments : noeuds, angle (degrés), longueur, (px, py) locaux, N, T, M au milieu de l’élément. Les efforts sont ceux de pb.Calcul_Def_Eff() (convention du code : M = EI v””, T = -dM/dx).

affichage_interactif.tableau_noeuds(pb, titre='Noeuds : déplacements et réactions (repère de structure)')¶

Tableau des noeuds : coordonnées, ddls (u1, u2, theta) et réactions (R1, R2, Mr). Les réactions sont celles de pb.reactions (nulles tant que pb.Calcul_Reactions() n’a pas été appelé).

affichage_interactif.tableau_valeurs_propres(liste_pb, noms=None, reference=None, nom_reference='Référence', titre=None)¶

Valeurs propres (pulsations en rad/s ou multiplicateurs de flambage) de un ou plusieurs problèmes, mode par mode. reference : liste de valeurs (analytiques…) ajoutée en dernière colonne, avec l’écart relatif du premier problème ; à n’utiliser que si elle correspond au même problème.

affichage_interactif.vue(pb, champ='u', ampli=None, representation='couleur')¶

Vue interactive d’un calcul statique : champ, représentation, amplification, options.

  • ampli : amplification initiale de la déformée (None : automatique, plus grand déplacement = 10 % de la taille de la structure) ; réglable ensuite avec le curseur.

  • representation : “couleur” (champ en couleur sur la déformée) ou “diagramme” (N, T, M).

La vue travaille sur une COPIE de pb faite à l’appel : la suite du notebook peut modifier pb (propriétés, nouveau calcul) sans changer ce qu’affichent les contrôles.

affichage_interactif.vue_modes(pb, mode=1)¶

Vue interactive des modes (flambage ou vibration) : choix du mode, animation dans la figure.

mode : rang du mode affiché au départ (1 = premier), comme “vp” dans pb.Affichage(“X”, …, vp).

La vue travaille sur une COPIE de pb faite à l’appel (cf. vue).
